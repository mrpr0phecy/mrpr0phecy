## Quick Setup (5 minutes)

### Step 1: Get a FREE API Key

Pick ONE of these (all completely free, no credit card):

| Provider | Free Tier | Quality | Get Key |
|----------|-----------|---------|---------|
| **Google Gemini** ⭐ | 1,500 req/day | Excellent | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| **Groq** | 1,000 req/day | Great (ultra-fast) | [console.groq.com/keys](https://console.groq.com/keys) |
| **OpenRouter** | Many free models | Varies | [openrouter.ai/keys](https://openrouter.ai/keys) |

**Recommended: Google Gemini** — most generous free tier, great quality, no credit card.

### Step 2: Add GitHub Secrets

Go to your repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

Add these two secrets:

| Secret Name | Value |
|-------------|-------|
| `AI_PROVIDER` | `gemini` (or `groq` or `openrouter`) |
| `AI_API_KEY` | Your free API key from Step 1 |

That's it! No other secrets needed.

### Step 3: Add the Workflow File

Create `.github/workflows/ai-developer.yml` in your repo:

```yaml
name: AI Developer

on:
  schedule:
    - cron: '0 6 * * 1,4'  # Mon/Thu at 6am UTC
  workflow_dispatch:
    inputs:
      task:
        description: 'Task type'
        required: false
        default: 'auto'
        type: choice
        options:
          - auto
          - audit
          - generate
          - fix
      category:
        description: 'Focus on specific category (leave empty for auto)'
        required: false
        default: ''
        type: string
      max_tools:
        description: 'Max tools to generate'
        required: false
        default: '3'
        type: string

permissions:
  contents: write
  pull-requests: write

jobs:
  ai-develop:
    name: AI Tool Developer
    runs-on: ubuntu-latest
    timeout-minutes: 15

    steps:
      - name: Checkout repository
        uses: actions/checkout@v4
        with:
          ref: main

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Run AI Developer
        id: ai
        env:
          AI_PROVIDER: ${{ secrets.AI_PROVIDER || 'gemini' }}
          AI_API_KEY: ${{ secrets.AI_API_KEY }}
          AI_TASK: ${{ github.event.inputs.task || 'auto' }}
          AI_CATEGORY: ${{ github.event.inputs.category || '' }}
          AI_MAX_TOOLS: ${{ github.event.inputs.max_tools || '3' }}
        run: node scripts/ai-developer.js 2>&1 | tee ai-output.log

      - name: Run verification
        if: steps.ai.outcome == 'success'
        run: |
          if [ -f scripts/verify.sh ]; then
            bash scripts/verify.sh || echo "Verification had warnings"
          fi

      - name: Create Pull Request
        if: steps.ai.outcome == 'success'
        uses: peter-evans/create-pull-request@v6
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          commit-message: 'AI Developer: automated tool improvements'
          branch: ai-developer/${{ github.run_id }}
          delete-branch: true
          title: 'AI Developer: New tools & improvements'
          body: |
            ## Automated AI Developer Run

            **Task:** ${{ github.event.inputs.task || 'auto' }}
            **Category:** ${{ github.event.inputs.category || 'auto-detected' }}

            ### What changed
            This PR was generated by the AI Developer workflow. Review before merging.

            ### Checklist
            - [ ] Tools render correctly
            - [ ] No external dependencies
            - [ ] All JS is IIFE-wrapped
            - [ ] Unique ID prefixes
          labels: |
            ai-generated
            automated

      - name: Upload log
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: ai-developer-log
          path: ai-output.log
          retention-days: 30
```

### Step 4: Test It

1. Go to **Actions** → **AI Developer**
2. Click **Run workflow**
3. Select `audit` task
4. Click **Run workflow**
5. Check the output in the log

## What It Does

### Automatic Runs (Mon/Thu 6am UTC)
1. Scans all 671 tools
2. Finds broken tools, weak categories, missing high-demand tools
3. Calls the free AI API to generate improvements
4. Opens a PR for your review

### Manual Runs
Go to **Actions** → **AI Developer** → **Run workflow**

Options:
- **Task**: `auto` (default), `audit`, `generate`, `fix`
- **Category**: Focus on specific category (e.g., "Board Games")
- **Max tools**: How many tools to generate (default: 3)

## Troubleshooting

### "AI_API_KEY not set"
Add the secret in repo Settings → Secrets → Actions.

### "No tools were generated"
Try:
1. Run `audit` first to see what's needed
2. Specify a category manually
3. Check the AI response in the log

### Rate limit errors
You've hit the daily limit. Wait 24 hours or switch providers.

## FAQ

**Q: Does this cost anything?**
A: No. GitHub Actions is free for public repos. The AI APIs have generous free tiers.

**Q: Do I need to keep my computer on?**
A: No. Everything runs on GitHub's servers. Your Mac Mini doesn't matter.

**Q: How often does it run?**
A: Twice a week (Mon/Thu at 6am UTC). You can also trigger it manually.

**Q: Will it break my existing tools?**
A: No. It only creates new files or fixes broken ones. All changes go through a PR.

**Q: Can I run it more often?**
A: Yes. Edit the cron schedule. With Gemini's 1,500 req/day limit, you could run it hourly.
