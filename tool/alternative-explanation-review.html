🧭 Alternative-Explanation Review

🧭 Alternative-Explanation Review

Review ordinary, testable possibilities for a specific observation before drawing conclusions. Each status and note is investigator-entered; the tool does not rank explanations or label anything paranormal.

A CHECKLIST IS NOT A DETECTOR
“Tested—not observed” means only that the recorded test did not observe that source. It does not eliminate the explanation. “Unresolved” or “not checked” is a valid outcome.
