🔐 Evidence File Integrity Manifest

🔐 Evidence File Integrity Manifest

Create a local inventory of selected evidence files with file metadata and SHA-256 hashes for manageable files, then append handling events. This helps detect later file changes; it does not prove where, when, or how a recording was made.

HASHES DO NOT PROVE AUTHENTICITY
Files are read in your browser only. SHA-256 is calculated for selected files up to 64 MB; larger files still get a metadata row but are not hashed. Keep original media read-only and document any transfer.
Nothing is processed until you click the button.
