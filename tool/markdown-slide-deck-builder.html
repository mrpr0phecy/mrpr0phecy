🎞️ Deck Forge

Write a presentation as plain text and present it from the browser. Split slides with ---, get a live thumbnail rail, speaker notes, a run timer and full-screen mode, then export a single self-contained HTML file you can email or host anywhere. No account, no upload, no £12/month slide app.

Slides — 0 total · 0 words
Keyboard shortcuts and the source format

While presenting: → / Space next, ← previous, Home/End first and last, S speaker notes, F full screen, Esc exit.

The format is deliberately small: # title, ## subtitle, - or 1. lists (indent two spaces to nest), > quote, triple backticks for code, **bold**, *italic*, `code` and [text](https://…) links. A line beginning Note: is a speaker note: it never appears on the slide. The exported HTML is one file with no external requests, so it works on a plane and on a conference laptop with no network.
