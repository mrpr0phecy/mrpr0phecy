📚 How to use this trainer

Learn — a field note appears; read it, picture the species, then tap Reveal.
Multiple-Choice — the field note is shown and you pick the species from four options.
Reverse ID — you see the species name and must pick the correct field note; this is the hard mode that tests whether features truly stuck.

Field notes use diagnostic features only: leaf arrangement/edges, flower structure, smell, habitat and season. Safety first: assume every fungus is toxic unless it is one of the unmistakable edible species AND you have confirmed it from a real field guide — the trainer includes lookalike warnings rather than safe-looking shortcuts.
