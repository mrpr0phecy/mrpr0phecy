🏉 Rugby Points Score Builder

🏉 Rugby Points Score Builder

Try 5, conversion 2, penalty 3, drop goal 3. Add up a score, or work backwards: give a points gap and this lists every combination of tries, conversions, penalties and drop goals that closes it — fewest scores first.

Notes

Point values are the union code standard. Conversions are capped at the number of tries — you cannot kick a conversion without a try. The combination list is ordered by the fewest scoring plays needed, then by tries first, because tries are the highest-value way to close a gap quickly.
