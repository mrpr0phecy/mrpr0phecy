Calculus Rules Reference

Power Rule
d/dx(xⁿ) = n·xⁿ⁻¹
∫xⁿ dx = xⁿ⁺¹/(n+1) + C
Trigonometric
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
Exponential/Log
d/dx(eˣ) = eˣ
d/dx(ln x) = 1/x
Product/Quotient
d/dx(f·g) = f'g + fg'
d/dx(f/g) = (f'g - fg')/g²
