Partition Layout Tips
• / (root) — 20–50 GB for OS + packages
• /home — user data, largest partition
• /var — logs, databases, mail queues
• /tmp — 2–10 GB, consider tmpfs
• swap — RAM size or 2× RAM (if hibernate)
• /boot — 512 MB–1 GB (EFI: /boot/efi 512MB)

Useful Commands
df -hT — disk usage with types
du -sh /* — directory sizes
lsblk -f — block devices
fdisk -l — partition table
