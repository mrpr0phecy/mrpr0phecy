📚 How the Math Works
Future Value Formula:
FV = P × (1+r)^n + C × [((1+r)^n − 1) / r]
Where:
P = Current savings
C = Monthly contribution
r = Monthly interest rate (annual rate / 12)
n = Number of months until retirement
Includes annual contribution increases
