📡 Linux Process & Signal Reference

Complete reference of Linux signals, process states, and process management commands with examples

Process States
RRunning / Runnable
SSleeping (interruptible)
DDisk sleep (uninterruptible)
ZZombie (defunct)
TStopped / Traced
IIdle (kernel thread)

Kill Hierarchy
1. Try SIGTERM (15) first — graceful
2. Wait a few seconds
3. Try SIGINT (2) — interrupt
4. Last resort: SIGKILL (9) — force

Never kill PID 1 (init/systemd)
Never kill D-state processes (I/O wait)

Quick Commands
kill -l — list all signals
ps aux --sort=-%mem — by memory
pgrep -f pattern — find by name
pstree -p — process tree
