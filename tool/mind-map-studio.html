🧠 Mind Map Studio

🧠 Mind Map Studio

A proper mind map in the browser: Tab for a child, Enter for a sibling, drag to rearrange, collapse branches you are not working on, and export as an image, a Markdown outline or a JSON file you can load back in later. Everything is drawn and saved on your own device — no account, no server, no upload.

Drag a bubble to move it · drag the background to pan · Ctrl (⌘) + scroll to zoom · double-click to rename
Keyboard, export formats and where your map is kept

Keyboard: click the map first (or press Tab to focus it) — the shortcuts only listen while the map has focus, so the rest of the page keeps working normally. Then, with a bubble selected, Tab adds a child, Enter adds a sibling, Delete or Backspace removes it (not on the root), and the arrow keys move the selection up, down, out to the parent and in to the first child. Typing in the box above renames as you go.

Exports: PNG is rendered from the map at twice the on-screen resolution with a transparent background. Markdown gives you the map as nested bullet points, ready to paste into notes or a document. The .json file is the whole map — save it and load it back with Load .json to carry on where you left off.

The map autosaves to this browser's local storage, so a refresh will not lose it. Clearing your browser data does. Nothing is uploaded and no network request is made: loading a .json file reads it from your own disk, and the PNG is generated on the device.
