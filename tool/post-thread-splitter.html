🧵 Thread Splitter for Long Posts

🧵 Thread Splitter for Long Posts

Split long text into a numbered thread that fits X, Bluesky, Mastodon or Threads limits, breaking at paragraphs and sentences rather than mid-word. Nothing is posted or uploaded.

Paste text, pick a platform, then split.

    Check the count in the app before posting. Limits shown are the usual defaults for standard accounts; paid tiers and some Mastodon servers allow more, so use a custom limit for those. Each platform counts some characters its own way, so this tool leaves the last word to the app's own counter.
