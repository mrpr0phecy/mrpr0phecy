🎭 AI Realistic Face Avatar — Procedural Canvas, FACS, Eye-Tracking, Lip-Sync

Byte 3.0's realistic face live — 100% procedural Canvas 2D, no images, no external models. Skin subsurface scattering, iris texture with flecks, micro-saccades, FACS action units (AU1, AU2, AU4, AU6, AU12, AU25), eye-tracking via mouse, lip-sync via TTS viseme. Same engine as Byte realistic face.

Move mouse over canvas for eye tracking — FACS emotions via buttons — fps
Face Controls — FACS
Tech: Procedural Canvas 2D, no images. Skin radial gradient + SSS + noise pores. Eyes sclera veins, iris radial + texture lines + flecks, pupil, double highlight, eyelids blink 140ms, micro-saccades 0.5-2s, tracking via mouse. Eyebrows bezier + hair strokes FACS AU1,AU2,AU4. Mouth lips gradient, teeth, tongue, FACS AU12,AU25,AU26 lip-sync via TTS amplitude. 60fps.
FACS: Facial Action Coding System (Ekman & Friesen 1978) — AU1 inner brow raiser, AU2 outer brow raiser, AU4 brow lowerer, AU5 upper lid raiser, AU6 cheek raiser, AU7 lid tightener, AU12 lip corner puller, AU15 lip corner depressor, AU25 lips part, AU26 jaw drop. Emotions via combinations.
Integration with Byte 3.0 thinking machine
This realistic face is the same engine used in byte-realistic.html — Byte 3.0's flagship interface. When Byte thinks (ToT BFS, Reflexion loop), face shows thinking (AU4+AU7) with ToT tree overlay. When speaking, mouth syncs via TTS viseme analysis (aou→0.7 open, ei→0.4, bmp→0.05). Eye-tracking follows mouse via FACS, with micro-saccades for realism. All procedural, no camera, no biometric data, 60fps, <50KB JS.
