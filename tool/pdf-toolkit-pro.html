How this stays free & offline

PDFs are not uploaded. FileReader reads them as ArrayBuffer in this tab; page counts and text are guessed from the raw bytes (counts of /Type /Page and strings in parentheses). Merging uses the browser's own print engine — we build a printable HTML document with each file in order, then you use Print → Save as PDF. Images → PDF uses a tiny built-in PDF writer (no library) that embeds JPEGs with DCTDecode. Compression re-encodes images at the quality you choose via <canvas>. Close the tab and the files are gone.
