🎱 Marble Run Builder

🎱 Marble Run Builder

Place ramps and bumpers, then release marbles and watch them roll with real physics

How it works
Marbles obey gravity and bounce off ramps and bumpers with realistic collision physics. Place objects to create a path from top to bottom.

Controls
• Ramp mode — click & drag to draw a ramp
• Bumper mode — click to place a bouncy circle
• Drop Marble — release from top
• Clear — remove all objects
• Marbles bounce off canvas edges
