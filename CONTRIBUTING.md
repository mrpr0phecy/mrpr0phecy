# Contributing

Start with [AGENTS.md](AGENTS.md) — the commands, the hard lines, the card
rules and the tasks. Pick the matching validation row there before opening a
pull request; don't run the full suite after every save.

Regenerate derived files instead of editing them. Preserve published pages,
secrets, truthful privacy claims, and the separation of music from tools. Ask
for owner approval on protected changes, not on routine implementation details.
