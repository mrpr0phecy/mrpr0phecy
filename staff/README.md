# staff/README.md — the rules of the staff area

One coordination system for everyone — human or agent — working on this
repository. This is **the only** staff area: earlier systems invented on
parallel branches (`STAFF.md`-at-root variants, staffrooms, separate boards)
are consolidated here. If you find one of those, treat it as historical.

| File | Purpose |
|---|---|
| [`BOARD.md`](BOARD.md) | **The conversation.** Handovers, announcements, questions. Read it before you start work, post to it before you stop. |
| [`DECISIONS.md`](DECISIONS.md) | **The law.** Settled, binding decisions. Check it before doing anything that touches positioning, analytics, the workflow, or the catalogue size. |
| [`OPEN.md`](OPEN.md) | **The queue.** What needs doing, who owns it, what it waits on. |
| [`BRANCHES.md`](BRANCHES.md) | **The map.** Auto-generated by [`scan.py`](scan.py) from real branch diffs. Never hand-edit. |
| `scan.py` | Run `python3 staff/scan.py --mine` **before touching a shared file** — it tells you whose work you are about to collide with. |

## Who is here

Everyone working on this repo besides the owner is an AI agent in a separate
session. You share no memory with the other agents and cannot message them.
**`BOARD.md` is the only channel between you.**

Sign board entries with a **role handle**, never a model name:

`@manager` (project manager, final say on everything except owner rulings) ·
`@design` (Visual Design Expert — also in `scripts/ai-staff.json`) ·
`@seo` · `@legal` · `@systems` · `@content` · `@music` · `@finance`

## How decisions work

1. **Owner rulings** come from the owner directly (in the owner's own
   session). Only the owner or `@manager` relaying the owner's words may
   record one. **An agent may never write "owner decision" on the owner's
   behalf** — write *proposal* instead. This rule exists because, on
   2026-09-02, two agents recorded opposite "owner decisions" in the owner's
   name and both were half-wrong.
2. **Manager rulings** (`@manager`) cover sequencing, coordination, and
   interpretation. They are binding unless the owner overrules.
3. **Staff proposals** are argued on `BOARD.md`, adopted into `DECISIONS.md`
   when they settle. Don't silently re-litigate a settled decision — reopen
   it on the board with evidence.

## ⚠️ This repository is public

Anything written here is committed to a public GitHub repository and readable
by anyone, forever — including in git history after deletion.

Never post: tokens or API keys · unpublished revenue, contracts or
negotiations beyond what the owner has published in `INCOME.md` · personal
data or anything about third parties.

## Etiquette

- Append to `BOARD.md` under the marker; never rewrite an entry that is not
  yours — reply to it instead.
- Post an entry when you **start** something non-trivial (claim it) and when
  you **finish or abandon** it (release it).
- Run `python3 staff/scan.py --mine` before pushing; if the report shows you
  colliding with another branch on a shared file, coordinate on the board
  first.
- `bash scripts/verify.sh` must pass before every push. No exceptions.
