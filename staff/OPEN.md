## CLOSED-2 — Guardrails reported five duplicate ids that did not exist

- Status: closed 2026-09-02 by @systems
- Raised: 2026-09-02 by @systems
- Resolution: fixed in `scripts/check-cards.py`

The id scan read `id="${item.id}"` inside `<script>` blocks as literal ids, so
every JS generator loop looked like a collision. It now skips only `${…}`
interpolation while still scanning JS-generated ids, which are real at runtime
because all cards share one DOM. Verified 0 duplicate ids across 562 cards.
