⚡ Byte 3.0 — Thinking Machine Research Stack 2022-2026

local-ai.html is now Byte 3.0 Thinking Machine — a full reasoning system that runs entirely in the browser, implementing the best AI research from 2022-2026:

🌳 Tree-of-Thought (ToT) — Yao et al. 2023

Branch into multiple thoughts, evaluate each 0-10, BFS/DFS search, backtrack. Visualized as tree with promising/pruned nodes. Enables deliberate problem solving vs single chain.

mode: tot · depth 3 · branching 3 · eval heuristic

🔁 Reflexion — Shinn et al. 2023

Verbal reinforcement learning: attempt → self-critique → retry with reflection. No weight updates, just verbal memory. Improves via self-reflection loop.

mode: reflexion · maxIter 2 · critique → retry

🗳️ Self-Consistency — Wang et al. 2022

Sample multiple reasoning paths (temperature>0), then majority vote for most consistent answer. Reduces single-path error.

mode: selfconsistency · samples 3 · confidence vote

🔙 Step-Back — Zheng et al. 2023

Abstract high-level principle first, then apply to specific. Improves generalization: "What principle applies?" before solving.

mode: stepback · principle → application

🪜 Least-to-Most — Zhou et al. 2022

Decompose complex problem into sequential subproblems, solve each building on previous. Handles compositional tasks.

mode: leasttomost · subproblems → workflow

🧠 ReAct — Yao et al. 2022

Reason + Act interleaved: Thought → Action (tool call) → Observation loop. Grounds reasoning in tool outputs.

mode: react · thought → ```tool``` → observation

📜 Constitutional AI — Bai et al. 2022

Self-critique against principles: grounded?, helpful?, honest?, harmless?, privacy?. Self-corrects without human feedback.

checks: grounded helpful honest harmless privacy

🔍 HyDE — Gao et al. 2022

Hypothetical Document Embeddings: LLM generates hypothetical answer, embed it, search with it. Bridges query-doc gap.

retrieval: HyDE embedding = query + tool-like terms

🔀 RRF — Cormack et al. 2009

Reciprocal Rank Fusion: fuse BM25 + embedding rankings via 1/(k+rank). Robust ensemble without tuning.

RRF k=60 · fused BM25 + embedding ranks

💎 MMR — Carbonell & Goldstein 1998

Maximal Marginal Relevance: balance relevance vs diversity. Avoids redundant results, λ=0.7.

MMR λ=0.7 · relevance - (1-λ)*maxSim

🧬 Generative Agents — Park et al. 2023

Memory with recency (Ebbinghaus exponential decay) + importance (LLM heuristic 1-10) + relevance (cosine). Weighted retrieval.

memory score = recency*0.2 + importance*0.3 + relevance*0.5

🧠 MemGPT — Packer et al. 2023

OS-style hierarchical memory: working → short-term → long-term → episodic. Reflection/consolidation of recent memories.

Worked example: Tree-of-Thought + HyDE + Reflexion

User: "Use Tree-of-Thought to plan a mortgage overpayment vs investment strategy for £250k at 4.2% with £30k savings"

  1. Step-Back first (if enabled): Principle = "Time value of money, risk-adjusted return, guaranteed vs risky, emergency fund first, debt hierarchy"
  2. HyDE retrieval: Generate hypothetical doc: "mortgage calculator tool compute estimate result overpayment loan interest" → embed → search. Query expansion adds loan, interest, repay, house.
  3. RRF fusion: BM25 ranking + embedding ranking (including HyDE) fused via RRF k=60 → robust list: mortgage, compoundinterest, budget, overpayment calculator
  4. MMR diversity: λ=0.7 — avoids redundant mortgage tools, picks diverse: mortgage calc, investment projection, budget tracker
  5. Cross-encoder re-rank: Joint query-doc scoring — token overlap + embedding → final order
  6. Tree-of-Thought (Yao et al. 2023):
    • Root: Goal mortgage overpayment vs invest
    • L1-0: Path A overpay — guaranteed 4.2% — score 0.8 promising
    • L1-1: Path B invest — potential 7% but risk — score 0.7 pruned
    • L1-2: Path C hybrid emergency fund + split — score 0.9 promising (best)
    • L2 expands promising: calculate numbers, verify grounding
  7. Least-to-Most decomposition: 5 subproblems: parse numbers → calc base → model overpay → project invest → recommend
  8. Model call with system prompt including ToT technique + site context + Generative Agents memory (recency+importance+relevance)
  9. Reflexion loop: Attempt 1: overpay £30k saves £18k. Critique: missed emergency fund. Attempt 2: hybrid £10k emergency + £10k overpay + £10k invest — improved, score 0.92
  10. Constitutional AI self-critique: Grounded? Yes mentions mortgage tool. Helpful? Yes substantive. Honest? No false action claims. Harmless? No false guarantees. Privacy? All local.
  11. Verification: Grounding score 0.8 — mentions mortgage, compoundinterest, budget tools that exist
  12. Model emits: 
    ```tool
{"tool": "create_workflow", "params": {"goal": "mortgage overpayment vs invest", "steps": ["calculate base mortgage £1348/mo", "model £30k overpay saves £18k", "project £30k @7% = £162k", "hybrid recommendation"]}}
```
  13. UI renders workflow with inline previews + ToT tree visualization + retrieval trace + constitutional check.

Why this works for small calculations

  • Private by construction — every tool computes in visitor's browser. No numbers uploaded.
  • Nothing to sign up for — no API keys, tokens, quotas. If you can GET it, you can use it.
  • Stable, hackable URLs — tool slugs never change; links keep working.
  • One canonical brain — local-ai-knowledge.json deterministic, reviewable, 7529 vocab, 1128 tools.
  • Research but offline — 3MB brain + runtime HyDE/RRF/MMR/ToT/Reflexion — no external AI API needed for retrieval or reasoning simulation.
  • Thinking visible — ToT tree, retrieval trace, constitutional checks, grounding scores — all shown in UI, not hidden.

House rules

  • Hot-linking, embedding, sharing tools is welcome — free forever, no attribution required (appreciated).
  • Tools are client-side helpers, not data source: they don't expose POST APIs or return computed JSON. Link or embed.
  • Content is general info, not financial/medical/legal advice — tools say so where it matters. Byte 3.0 adds disclaimer + Constitutional AI check.
  • Byte 3.0 is local-first: model + brain cached in browser. First load downloads weights; no conversation sent to AI service. Demo mode uses full research stack without model.
