Is the service worker behaving?

This page drives the site's cached navigation layer the way a visitor does — a run of real page loads, one after another — and says plainly whether it stalls, or shows a page you did not ask for. Nothing is sent anywhere: every number below is read from this browser.

Checking…

The first button is the test. The second switches the worker off (and clears the cache) so you can see whether the site is fine without it — which is the quickest way to settle where a problem lives. Nothing here needs a redeploy.

What each row means

slow — answered, but over 2.5 s; usually a busy origin, not the worker.
wrong page — the address in the frame and the page it rendered disagree. This is the failure that was reported, and it is a bug in the worker, full stop.
did not load — the origin never answered twice. The worker shows an honest failure at the URL you clicked rather than substituting another page.
no reply — the frame never finished. Treat this as a stall and say so.
