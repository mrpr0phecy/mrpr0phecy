🗺️ MostUsefulMaps — Distance & Place Finder

The site's own map, right here in the card. Drop two points — a town name, a coordinate pair, a Plus Code or a UK grid reference — and get the geodesic distance on the WGS84 ellipsoid, the initial bearing, the Plus Code of each end and the nearest town to each. Everything is computed on your device from data shipped with the page, so it works with the network switched off. The full map adds live OpenStreetMap streets, road routing, measuring, elevation and sun times.

Distances are geodesic (Vincenty on WGS84) — the same figure a surveyor's GNSS software reports, not a flat-map approximation. Road distance, live streets and turn-by-turn directions are on MostUsefulMaps, built on OpenStreetMap data with no API keys and no account. Offline map: Natural Earth (public domain).
