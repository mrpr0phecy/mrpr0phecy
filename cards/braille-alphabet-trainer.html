🔵 Braille Alphabet Trainer

Learn the 26 letters of English Braille by building cells dot by dot and decoding them. Each letter is a 2×3 grid of raised dots — once you see the pattern, the whole alphabet unfolds. All local, nothing sent anywhere.

The alphabet — dots 1–6
Dot numbering: left column top→bottom is 1, 2, 3; right column top→bottom is 4, 5, 6.

See the logic: a–j use the top four dots (1,2,4,5); k–t add dot 3 to the a–j pattern (k = a + dot 3); u–z mostly add dots 3 and 6. That structure makes Braille far easier to learn than 26 random shapes. Numbers use a–j with a number sign before them.
