🔗 URL Encoder & Query Builder

Encode or decode URL text safely, then inspect, edit and rebuild query parameters without losing special characters. It is useful for sharing links, debugging redirects and preparing search or campaign URLs — entirely offline.

A quick encoding rule

Use URL component for a query value such as a search term: it encodes &, ? and #. Use complete URL only for a whole link, because it keeps its separators readable. The query builder uses standard URLSearchParams encoding, where a space appears as +.
