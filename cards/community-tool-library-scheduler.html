Community Tool Library Scheduler

Turn a shared equipment list and borrowing requests into a conflict-checked lending schedule. Track which items are available, flag double bookings, and leave time for return and inspection.

A schedule is not permission or a safety inspection. Agree liability, maintenance, age restrictions and local insurance requirements; hazardous equipment needs qualified supervision. Browser-only worksheet: no uploads, accounts or automatic saving. Use one agreed master copy; this is not a synchronised multi-user service. Export before closing and share only with consent.

One line: unique item ID | description

One line: item ID | borrower alias | start YYYY-MM-DD HH:MM | end YYYY-MM-DD HH:MM

Community proposal

    How this works and what it cannot do

    Requests are accepted in listed order if their half-open time interval, plus the return buffer, does not overlap an already accepted request for the same item. All times are wall-clock times in one agreed local zone, with no DST conversion. This is a worksheet, not a live reservation server.

    Agree participation, decision rules and responsibilities locally. These tools do not guarantee prosperity, check legal compliance or replace essential public services. No government funding or administration is assumed.
