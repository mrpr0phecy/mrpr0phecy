Octal Values

Special Bits
setuid (4xxx) — run as file owner
setgid (2xxx) — run as file group
sticky (1xxx) — only owner can delete

Common:
chmod u+x file — add execute for owner
chmod go-w file — remove write for group/others
chmod -R 755 dir/ — recursive
