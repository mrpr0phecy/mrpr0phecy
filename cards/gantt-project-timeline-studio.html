📊 Gantt & Timeline Studio

Draw a real project timeline — tasks, dates, progress, milestones and dependencies — and export it as a clean SVG or a print-resolution PNG. TeamGantt and Microsoft Project charge per user per month for a chart that is, at heart, rectangles on a date axis. This one runs offline, keeps the plan in your browser, and hands you a vector file you can drop into a slide, a proposal or a client update without a subscription or a watermark.

Importing a plan, and what the arrows mean

"After #" is the row number of the task that must finish first — arrow tails start at the end of that task and land on the start of this one, drawn as elbows so they never cut through a bar. Tick M on a row with the same start and end date to turn it into a milestone diamond, which is how deadlines and sign-offs are usually shown.

You can paste a plan in as CSV instead of typing: one task per line, task, start, end, percent, after, owner — dates as YYYY-MM-DD. The quickest way to start is to export a CSV from any spreadsheet app, or to press Load example, export its CSV and edit that. Rows that cannot be parsed are skipped and reported rather than silently dropped.

The chart itself is generated as SVG markup, so the PNG export is a rasterisation of the same drawing at three times the size — text stays sharp in the SVG at any zoom. The plan is saved in this browser, so it survives a refresh but not a different device; keep the CSV as your portable copy.
