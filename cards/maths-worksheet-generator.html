How the questions are chosen, and how to use the sheets well

Reproducible sheets. Every worksheet has a number (the seed shown next to the buttons). The questions are generated from that number, so the same settings and seed always give the same sheet — that is what the Copy link button shares, which makes it easy to give a class or a tutoring group identical work and still have the answer key match. New questions just picks a new seed.

What the options do. No carrying / borrowing keeps every column of an addition below ten and every column of a subtraction non-negative, which is the right restriction while a child is still learning the written method; turn it off once regrouping has been taught. Division questions are built backwards from a times-table fact so they always work out exactly unless you allow remainders, in which case the answer is written as, for example, 7 r 2. Missing-number questions hide one operand of an addition or subtraction, the first step towards algebra. Number bonds ask for the partner that completes 10, 20 or 100. Subtraction never goes negative, and in the stacked layout the larger number is always on top.

Using them. Twenty questions is a comfortable ten-minute session for most primary-age children; sixty in five minutes is a classic times-tables speed test. Mark with the answer page rather than in your head, and keep the sheets — repeating the same seed a week later shows whether a skill has stuck. The PDF uses real text, not pictures, so it prints crisply at any size, and the layout leaves room for working in the stacked format. Nothing is uploaded; the sheet is built entirely in your browser.
