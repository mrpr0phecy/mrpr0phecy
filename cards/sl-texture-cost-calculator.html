Best Practices
• Use 512×512 for most clothing/skin
• Use 1024×1024 for detailed faces/signs
• Avoid 4096 unless absolutely needed
• Always use power-of-2 dimensions
• Lossy for photos, lossless for text/logos
• Each texture uses VRAM = W×H×4 bytes
