01.Get started

How many tools are there, and how do I find one?

There are 562 free tools across 23 categories — Science & Engineering, Mathematics, Finance, Health, Music, AI & more. Use the search bar at the top of the page (or press / from anywhere), then narrow with the category pills underneath.

Three quick ways to discover things:

1. The Featured tool of the day on the home page — one curated pick, same for everyone, rotates at midnight UTC.

2. The Search matches tool names, descriptions and categories in real time.

3. The Directory view (top right of the catalogue) gives a fast, scannable list — useful when you know roughly what you want.

What are the keyboard shortcuts?

Press ? anywhere to see them all. Highlights:

/ — focus the search bar   ·   R — open a random tool   ·   Ctrl+T Toolbox   ·   Ctrl+P theme palette   ·   Ctrl+R reader mode   ·   Ctrl+D support panel   ·   Ctrl+S suggest a tool   ·   Ctrl+V toggle card / directory view   ·   Ctrl+0 reset all filters   ·   [ / ] cycle categories   ·   Esc close any open panel or modal.

Can I open a tool in a new tab or fullscreen?

Yes. Every tool has a Standalone button in its card header that opens a focused, fullscreen modal — perfect for keeping several tools open at once. Inside the modal, Open in New Tab gives you a permanent URL you can bookmark or share.

02.Privacy & tracking

Do the tools track me or send my inputs anywhere?

No. Every tool runs entirely in your browser. Inputs never leave your device. None of the tools use analytics, none set tracking cookies, none fingerprint you.

The only network calls the site itself makes are: Google Analytics on a handful of pages (to count visitors — not to track you across sites) and the YouTube embed on the music pages (which loads only if you press play).

Do I need to sign up, give an email, or create an account?

No. The whole site works without an account of any kind. The only things stored on your device are: your theme preference, the tools you added to your Toolbox, the rating votes you cast, and the list of tools you recently used (visible on the home page).

Why do I see ads on some pages?

You don't. The Most Useful Site has no ads, no affiliate links, and no sponsored content on its tool pages. Sponsorship is sold separately (one tasteful placement per category) and is clearly labelled.

03.Sharing & embedding

How do I share a specific tool with someone?

Every tool has a permanent URL of the form themostusefulsiteintheworld.com/tool.html?card=tool-name. Open the tool, click Share in the header, and the link is copied to your clipboard. Send that — the recipient lands directly on the tool, no sign-up, no friction.

Can I embed a tool on my own website or blog?

Yes. Open any tool, click the Embed button in the card footer, and a copy-paste iframe snippet goes to your clipboard. The tool loads from this site; you don't host anything, and you can take the embed down any time by removing the iframe.

Can I share my Toolbox with someone?

Right now your Toolbox is per-device (it's stored in your browser's local storage). For a sharable Toolbox, copy each tool's standalone link from its Share button and bundle them in a doc or message — that works perfectly for a "tools I use every day" recommendation.

04.Offline use

Do the tools work without internet?

Once a tool has loaded once, your browser caches the page and the tool keeps working on that device even if you disconnect. A service worker for fully-managed offline use across all 562 tools is on the roadmap.

Can I install this as an app?

The site is configured as a PWA (manifest.json is in place), so most modern browsers will offer an "Install" option from the address bar. Once installed it opens in its own window with no browser chrome. The full app experience is opt-in.

05.Your Toolbox

What is the Toolbox?

The Toolbox (🧰) is a docked, draggable window that holds the tools you use most. Two view modes: Grid (a resizable tile grid) and List (an expandable list). Add a tool with the 🔲 or 📋 button on any card. Reorder by dragging. Empty it whenever you want — nothing is uploaded.

Where is my Toolbox saved? Can I sync it across devices?

Your Toolbox lives in this browser's local storage — it's not on a server, and it does not sync between devices. If you want the same set on another device, open the Toolbox on this device, copy each tool's standalone link, and rebuild it there. (Sync is on the wishlist, not on the roadmap yet.)

06.Requesting tools

How do I suggest a new tool?

Three easy ways:

1. Press Ctrl+S anywhere on the site.

2. Click the 💡 icon in the top bar.

3. From the home page — the suggest-a-tool button is in the dock.

Tell me what the tool should do, which category it belongs in, and (if you can) what a great version of it would look like. The most-requested ideas get built next — typically within a week or two.

Can I build a tool for the site myself?

If you can write HTML and JavaScript, you absolutely can. Each tool is a single self-contained HTML fragment in the /cards/ directory. The full onboarding is in ARCHITECTURE.md on GitHub — start with §3 (How the catalogue works) and §6 (SEO). Pull requests welcome.

07.About this site

Who built this? Why?

Russell Head, a developer in Luton, England. Also known as MrProphecy for music. The site is built and maintained by one person because the alternatives — ads, accounts, paywalls — all break the simple promise of a useful page that just works.

What's the stack? Where does it run?

Static HTML, CSS, and JavaScript. No framework, no build step, no dependencies. Hosted on GitHub Pages, served straight from the main branch with 30–60s deploy latency. Total repo size ~125 MB; the site itself is <1 MB on first load thanks to lazy-loading and per-card fetching.

What other things live on this domain?

Two products, deliberately kept separate. The Most Useful Site in the World (this — the 562 tools) and MrProphecy (UK hip-hop and animated soundscapes, also free). Cross-links are kept minimal on purpose — each side respects the other's audience.

08.Funding & support

How is this site funded?

Honestly: it isn't, mostly. Hosting is free on GitHub Pages; the only real cost is the domain, which renews yearly. Some users chip in via the donate and sponsor pages; that money covers the domain and the hours to keep building new tools.

Can I sponsor a tool or a category?

Yes — see the sponsor page. Sponsorship is a single tasteful placement on a category or tool page, with real numbers sent on request. No banners, no popups, no autoplay, no ad tech, no off-site tracking.

Will the tools always stay free?

Yes. The deliberate positioning is that nothing here is gated. The only thing that changes if you donate is the speed at which new tools appear — not what you get access to.

09.Troubleshooting

A tool is broken, slow, or has bad data. What now?

Use the 👎 button in the tool's footer to mark it. That bumps its priority on the next build pass. For a specific bug, the 💡 Suggest a tool dialog has free-text — describe what went wrong and which tool it happened on. (Suggestions are stored locally; to follow up by email, use the contact on the sponsor page.)

The catalogue won't load — I just see "No cards found".

Two usual causes:

1. Local file:// access — opening index.html directly blocks the fetch() for cards.json. Always serve the site over HTTP (e.g. python3 -m http.server 8891).

2. Ad-blocker or privacy extension blocking the JSON. Try a different browser or temporarily disable extensions on the site.

I broke my Toolbox by accident. Can I undo?

Use the 🗑 Clear All button in the Toolbox title bar. There's no undo — the data lives in local storage and clearing is instant. (If you had things you cared about, those tools are still in the main catalogue; you can re-add them from there.)
