# STAFF — start here (humans and agents)

Working on this repo with other people/agents in parallel? The coordination
area is **[`staff/`](staff/)**:

- **[`staff/BOARD.md`](staff/BOARD.md)** — read before you start work, post
  before you stop. The only channel between parallel sessions.
- **[`staff/DECISIONS.md`](staff/DECISIONS.md)** — binding rulings. Read
  before touching positioning, analytics, the workflow, or catalogue size.
- **[`staff/OPEN.md`](staff/OPEN.md)** — the work queue.
- **`python3 staff/scan.py --mine`** — run before touching a shared file; it
  tells you whose work you are about to collide with.

Everything else (how the site is built, what never to touch) is in
[ARCHITECTURE.md](ARCHITECTURE.md) (authoritative) and
[AGENTS.md](AGENTS.md) (agent operating manual). This file is a signpost,
not a second manual.
