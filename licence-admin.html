🔑 Licence admin

Owner console for the embed licence product (STRATEGY.md). Everything here runs in this browser — the private signing key never leaves this device and nothing on this page calls the network. This page is noindex and carries no analytics.

This page is not in a secure context (crypto.subtle unavailable). Open it over HTTPS (GitHub Pages) or from file:// in a normal browser window. Key generation is disabled until then.

1 · Your signing keypair

Generate once, keep forever. The private half signs licences; the public half goes into embed.html's mus-licence-pubkey meta tag so snippets can verify buyers. Stored in this browser's localStorage — export it and keep a copy somewhere safe (password manager), or a cleared browser = no way to issue renewals under the same key.

Import an existing keypair instead

2 · The one-time wiring step

Paste the public key into embed.html — find <meta name="mus-licence-pubkey" content=""> and put the JWK between the quotes. Commit and deploy. Until this is done, activation on embed.html stays switched off and every embed is the free credited tier (the safe default).

3 · Issue a licence

After payment clears: enter the buyer's site, pick a tier, sign, email the key. Whitelabel keys carry domain * (any site). Default expiry is one year out — renewal is issuing a fresh key.

4 · Verify a licence (sanity check)

Paste any key to check it against your public key, optionally with a hostname to simulate the buyer's site.

How enforcement works (honest version)

The licensed snippet embeds a verifier that checks the key's ECDSA signature against the public key in embed.html, checks the page hostname against the licensed domain, checks expiry — and only then removes the credit line. It is tamper-evident, not DRM: a licensee could delete the verifier from their copy, which is a licence breach (detectable the same way uncredited embeds always were — the tool still links back unless they strip that too). What this scheme guarantees is that keys can't be forged, shared across unlicensed domains, or used after expiry. Format and crypto live in scripts/licence-keys.mjs; regression tests in scripts/tests/licence-keys.test.js run in verify.sh.
